## The wall

Image collection is a filtering problem disguised as a download problem. The page has hero shots, thumbnails, tracking pixels, lazy-loaded variants, and the same photo at four resolutions. Saving everything gives you a folder you'll never sort. Saving the visible ones gives you the 200 px thumbnail.

This extension collects what the page actually uses, lets you filter and compare, then downloads once.

## What changes

**Metadata filters that match how you judge images.** Dimensions, megapixels, aspect ratio, alpha, animation, EXIF, DPI confidence. Filter to the 2000 px and up with transparency, then look at what's left.

**Content de-duplication.** Exact duplicate content gets grouped so the same asset doesn't arrive five times under five URLs.

**Deep crawl with guard rails.** Seed URLs, depth limits, origin rules, and page caps. It explores linked pages on purpose instead of wandering.

**Naming you can work with.** Build filenames and folder structure from site, page, size, type, date, or hash. No more `image_0047.jpg` in a flat folder.

**One-time conversion.** Original files, or convert the selection to JPG, PNG, or WebP once on the way out.

**A queue that survives a long session.** Successful work and diagnostics stay available while the job runs.

**Archives built incrementally.** Streaming ZIP means a 4 GB set doesn't need 4 GB of memory.

**Preview and select in place.** Previous and next through results, pick from the modal, no separate tab juggling.

## Who it's for

Designers building mood boards and reference sets. Researchers collecting figures from papers. Anyone assembling a product image set for a store, a deck, or a catalog.
