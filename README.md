## Overview

Xtreme Download All Images is built for modern websites where the image you can see is not always the image a simple downloader can find. It can discover resources from standard elements, responsive sources, lazy galleries, CSS, inline SVG, canvas, Blob/data URLs, open tabs, URL lists, redirected links, and optional linked-page crawling.

From discovery to delivery, the extension is designed as a complete collection workflow: inspect metadata, filter results, choose stronger variants, de-duplicate by content, control naming, convert formats, preview selections, queue jobs, and package large result sets efficiently. It is aimed at designers, researchers, archivists, content teams, developers, asset collectors, and power users who need control rather than a one-click black box.

## Key features

- **Deep image discovery** across page resources, frames, responsive images, lazy-loading attributes, CSS, SVG, canvas, Blob/data URLs, linked pages, open tabs, and URL lists.
- **Metadata-aware filtering** for dimensions, megapixels, aspect ratio, bit depth, alpha, animation, EXIF/GPS presence, DPI confidence, source type, and more.
- **Quality-aware candidate selection and exact-content de-duplication** to reduce repeated or lower-value variants.
- **Download-all conversion prompt** with original, JPG, PNG, and WebP choices while preserving saved quality preferences.
- **Controlled naming and folder templates** using page, site, dimensions, type, orientation, date, hash and other useful placeholders.
- **Progressive previews, persistent queues, byte caching, and incremental ZIP creation** for larger collections and more resilient sessions.
- **Optional deep crawl with origin/depth/page safeguards** for controlled exploration beyond the current page.
- **Privacy-focused operation** with no analytics, telemetry, affiliate injection, or remote executable code in the product design.

## Standout tools and workflows

| Tool / workflow | Why it matters |
|---|---|
| **Download All + Convert** | Collect the full selection and choose original files or a one-time JPG, PNG or WebP conversion. |
| **Deep Crawl** | Explore linked pages from controlled seed URLs with depth, origin and page-count safeguards. |
| **Metadata Filters** | Narrow results using dimensions, megapixels, aspect ratio, alpha, animation, EXIF, DPI confidence and other technical attributes. |
| **Content De-duplication** | Identify exact duplicate image content so repeated assets do not become repeated downloads. |
| **Smart Naming** | Build filenames and folders from page/site/size/type/date/hash and related metadata. |
| **Persistent Queue** | Keep successful work and structured diagnostics available during longer download sessions. |
| **Streaming ZIP** | Build large archives incrementally instead of requiring the full package to exist in memory at once. |
| **Full Preview** | Move through results with previous/next controls and select directly from the modal preview. |
